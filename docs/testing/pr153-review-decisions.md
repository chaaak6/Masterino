追加的代码与实测结论：

- 字典只有其他语言名称时不冒充当前语言翻译。服务端返回实际采用的语言，客户端按语言族匹配，否则用已有本地化文案回退；中文变体仍可采用中文字典。
- 投稿者传入的 metadata 不得包含管理员确认时间。原子投稿、初建资源及旧上传路径移除该保留字段；旧更新路径保留已有服务端确认时间。既有后端测试补了伪造时间输入。
- 不给每次发布写全局分类确认时间：版本审核的确认只作用于所审版本，后续新投稿应重新展示新建议。V1 发布前/后管理员改类与 V2 新建议均有实际 UI 验证。
- 同一包重新选择分类时，原有幂等返回提前退出会丢掉建议。新增 nullable `suggested_category` 作为可变审核元数据，旧记录兼容读取 editor_data；仅待审状态、建议确有变化时更新分类建议并审计，保留原提交时间，避免撤销后来的管理员确认。不更改包内容、版本数、线上资源分类或版本指针。
- 无有效分类的已批准 Skill 继续禁止发布，同时显示“发布前请选择有效技能分类”，避免只禁用按钮却不说明原因。
- 社区详情在 Electron 中缺少实际安装入口。复用已有 Market 安装服务和刷新动作，加独立安装/手动更新按钮，保留 ZIP 下载入口；不自行判断远端有新版本。实测同一聊天安装后 `/` 可见并激活，更新后正文和 reference 均为 V2。

最终测试与 CI 以 PR 最新提交和验收记录为准。新增数据库迁移只增加分类定义与审核元数据字段，不同步两套环境的业务资源。
