# Masterino 桌面集成验收用例

## 准备

- 使用本次集成分支的 Electron 测试构建。设置页确认服务器为 `https://mlai-test.bielcrystal.com`。记录客户端提交、服务器镜像 digest、系统版本、测试账号代号和设备代号。
- 使用获授权的同一测试账号登录两个独立的设备身份，记为 A、B。同一台 Mac 的两个普通资料目录共享机器身份，因此需要两台机器，或使用已有的双设备身份测试构建。账号隔离另备第二个授权测试账号。Windows 验证使用 Windows 测试包。
- 在 A 创建合成项目，包含 `AGENTS.md`，写入「每次答复包含 QA_AGENTS_1122」。准备一个长路径项目，路径含中文、组合重音或 emoji。另准备 macOS 下载目录下的项目副本。
- OpenCADStudio 打开合成 DXF，用「QA-1122」标注。需要编辑时先保存副本，确认工具返回内容可用于测试服务与模型。
- 开发者工具 Network 勾选 Preserve log，按 `oidc`、`chat/newapi`、`connector`、`mcp`、`message` 筛查。只记录请求路径、状态、请求 ID、调用次数和脱敏结果。
- 受控的 503、EOF 和总超时使用本地流式故障夹具。真实测试服务对话单独验证。使用现有测试服务和网关，夹具运行在本机。

- 单副本更新使用 `maxSurge: 0`。首次拉取近两分钟，超过首次就绪预算后自动回退。镜像缓存后的重试成功，应用就绪副本为 1，授权配置端点返回 HTTP 200。期间测试站短时返回 503。

## 默认助理固定回复复验

默认助理「小宗狮AI」的 `chatConfig.inputTemplate` 留有测试指令 `Reply exactly CUTOVER_OK. Do not use tools.`。这条模板没有 `{{text}}`，因此 [输入模板处理器](../../packages/context-engine/src/processors/InputTemplate.ts) 将发送给模型的用户消息替换成同一条测试指令。会话里仍显示用户原始问题，容易被误判为上游模型返回固定内容。

通过 Electron 参数面板清空这一个预处理模板。通过现有的测试 PostgreSQL 只读核对，模板已清空，助理的其余字段和聊天设置没有变化。此项修复适用范围是该测试账号的默认助理，继续使用已有的测试服务。

同一账号、同一默认助理和同一个 DeepSeek V4.1 Flash 模型，在独立话题发送相同问题「23 加 19」。修复前回复 `CUTOVER_OK`，修复后回复 `CUTOVER_QA_173 42`，继续追问折扣计算时正确回复 `59 元`。两次正常回复均已保存。输入模板处理器现有 6 项测试通过。

| 已保存的本机连接 | 在测试自托管资料中保存 MCP 连接，同一服务器地址切换有无尾部斜杠并重新打开设置。两个窗口同时保存不同连接。              | 原连接可读、可调用、可编辑，两个窗口新增的连接均保留。                                                                                               |
| 流式工具调用     | 使用先输出工具增量的夹具，分别主动停止以及模拟网络断流。                                                               | 主动停止后保留可标记为已取消的工具记录。网络断流不会把不完整工具交给执行器。                                                                         |
