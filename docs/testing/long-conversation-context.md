# 长会话与 Agent 续跑验收

## 测试环境

- 本地 Electron 测试应用使用独立配置目录，连接 `masterino-test`。在开发者工具确认 API 域名和本次构建版本。
- 记录服务端镜像 digest 和现有 Pod UID。原地更新容器镜像后，核对 UID、就绪状态和新 digest。测试期间以本次构建响应为准。
- 使用专用测试会话与合成内容。工具任务只写入专用临时目录，人工批准时核对实际路径。
- 开启 Electron 开发者工具的 Network 和 Preserve log，记录步骤号、请求类型、消息角色、调用与结果是否配对。附证据时去掉登录信息及消息、附件正文。

## 测试数据

| 数据       | 内容                                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 普通聊天   | 新会话。首条消息要求记住 `QA-NORMAL-734`，第二条问回该标记。                                                                 |
| 普通任务   | 在测试目录新建 `qa-context.txt` 写入 `QA-TASK-314`，再调用工具读回并汇报。                                                   |
| 千条边界   | 预置 1,000 条完成消息，尾部有唯一标记 `QA-TAIL-1000`。通过界面发送下一条消息，要求调工具并引用工具结果和尾部标记。           |
| 长会话     | 所选路径有 3,000 条短消息，分别在早期、1,000 附近和末端放唯一标记。第 2,921–3,000 条之间有完整轮次和工具结果。               |
| 分支与摘要 | 从同一旧问题分出 A、B 两条回答，分别含 `QA-BRANCH-A` 和 `QA-BRANCH-B`。准备只覆盖公共历史的摘要，以及只适用于 A 的后继摘要。 |

## 点击用例

| ID  | 操作                                                                                             | 通过条件                                                                                                      |
| --- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| C01 | 新建普通聊天，发送首条消息并等待流式完成。追问标记，切换会话后回来并刷新。                       | 两轮回复正常，追问给出正确标记，完整消息顺序在重开后保持。                                                    |
| C02 | 在普通会话中重新生成一个回答，切回原回答，再从原回答追问。                                       | 两个回答可切换，追问使用原回答分支。                                                                          |
| T01 | 发普通任务，批准写入和读取，等待工具返回及最终回答。                                             | UI 显示调用与结果，实际文件内容正确，最终回答引用正确结果。                                                   |
| T02 | 再做一次普通任务，拒绝一次工具调用。随后在同一会话继续聊天。                                     | UI 显示对应拒绝状态。后续聊天正常，拒绝的工具没有执行。                                                       |
| L01 | 打开千条边界会话，从界面发带工具的任务。工具执行期间切出再返回。                                 | 下一次模型请求包含第 1,000 条之后的助手调用和工具结果，最终回复引用正确结果，日志没有把重复指纹报成上游超限。 |
| L02 | 打开没有摘要的 3,000 条会话，追问末尾标记并继续一个任务。向上翻过第 1,000 条，直至最早标记。     | DevTools 显示最新 50 条，随后请求携带游标。刷新保留旧页和阅读位置。翻页有确定顺序，追问和工具能够正常结束。   |
| L03 | 打开已有有效摘要的长会话，追问摘要里的旧决定和最近一轮的精确值。                                 | 摘要与近期原文都生效。服务端观察到摘要边界之后的原文读取量，旧前缀正文无需重新装载。                          |
| L04 | 在分支会话切换 A 和 B，各发一次只依赖该分支的追问。编辑 A 摘要范围内一条旧消息，然后重开并继续。 | 两个分支分别命中对应标记。编辑后使用新值，沿 A 回退至仍有效的公共摘要或原文。                                 |
| L05 | 在长会话发起有审批的任务，等审批界面出现后重开应用，再批准并继续。                               | 恢复原操作，已完成结果复用，已有调用与结果一起进入下一次请求。                                                |
| L06 | 在长会话运行一个返回长日志的任务，要求用范围读取核对一个具体旧报错。                             | 原调用与结果保持配对，Agent 引用可回查的证据，超长预览不会重新把全文塞进请求。                                |
| L07 | 在同一分支压缩早期轮次，继续完成一批轮次后再次压缩。重开并追问两批中的决定，然后编辑第一批原文。 | 恢复请求只带最新滚动摘要和未覆盖原文。时间线保留原文及「消息已压缩」标记。编辑后沿有效摘要边界或原文恢复。    |

| L08 | 打开至少 121 条记录的会话。滚到首屏最早消息上方，逐页加载，直到看见第一条原文。 | Network 中每页最多 50 条，后一页使用前一页的游标。最终能看到完整首条正文，继续上翻不会重复加载。 |
| L09 | 从带长 B 分支的会话打开短 A 分支，重新生成，切回旧回答，再刷新停在该会话。 | 首屏只返回 A。新回复与两个旧回复均可选择，切到旧回答后没有 B 的消息。Electron 菜单刷新后输入框和历史都恢复。 |
| L10 | 从长会话调用返回 40–60 KB 合成文本的工具。要求按归档提示读取被预览省略的唯一标记。 | 工具预览带 VFS 路径和文档 ID。Agent 使用文档工具从归档读回正确标记。刷新后仍能看到工具调用、归档提示和回复。 |
| L11 | 用 Gateway 运行含两次工具调用的任务，中途刷新，再翻回已加载的旧页。 | 重连能恢复同一运行。Network 可见按本轮助手 ID 获取的变更批次，旧页不会被完成事件覆盖，下一轮提示仍包含调用和结果。 |

## 自动化验收

| 场景                   | 可观察断言                                                                   |
| ---------------------- | ---------------------------------------------------------------------------- |
| 1,003 条真实数据库记录 | 按 ID 读取确认与正常模型续跑都能得到第 1,001 条之后的调用与结果。            |
| 历史响应迟到           | 写入确认或流式更新之后返回的旧数据无法丢掉当前消息。                         |
| 路径分页               | 游标覆盖同时间戳的多条消息，分支和工具关系可跨页恢复。                       |
| 摘要覆盖与故障         | 读取只跨有效边界。源记录修改、摘要失败、重复发布或晚到工具结果不会隐藏原文。 |
| 错误来源               | 本地重复、缺少工具结果与上游长度拒绝分开记录。上游拒绝恢复最多一次。         |

逐项记录通过、失败或阻塞。每个失败附复现步骤、Electron 请求证据、服务端关联日志及修复后复验结果。
