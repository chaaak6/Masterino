# PR #153 技能分类与社区统计验收用例

本用例供测试人员按真实界面执行。测试 App、API、Market、管理后台均连接测试集群；测试和生产各自保留资源，数量无需相同。生产资源、分类和部署不在本轮操作范围内。

验收前记录 PR 提交号、测试 App 路径/版本、API/Market/后台实际运行版本、测试账号、工作区和测试时间。确认后台为 `admin-mlai-test.bielcrystal.com`，App 请求进入测试集群。本机开发服务或独立测试预览可以承载本次代码，但最终验收必须在 Electron 测试 App 中进行。

打开 Electron 开发者工具，Console 保留日志，Network 记录分类/列表、投稿、审核、下载等关键请求；同时跟踪该测试 App 的主进程日志和本次测试服务日志。记录操作、可见结果、请求状态和相关错误；证据隐去令牌、密码、Cookie 及真实业务文件内容。不能以接口成功、按钮被点击或源码单测代替真实功能成功。

准备独立目录和带 `QA-153-日期` 前缀的合成技能：A 为带 reference 文件的 ZIP，正文输出固定标记 A_V1；B 为对话中创建的个人技能，正文输出 B_V1；A 的 V2 改正文标记与描述。另保留一个旧包（没有分类字段）、一个历史空分类资源，以及一个分类不在已知字典中的旧资源。两个普通账号用于验证作者/非作者可见范围，后台账号负责审核。沿用已存在的账号和授权，不改变生产权限。

每个用例的实际结果、证据路径、失败原因/修复提交和复测结果单独填写。P0 均须通过；无法实际执行的用例标为未验证，不记为通过。仅保留少量后端规则与接口契约单测，主要 UI 验收按以下步骤完成。

测试人员应针对每条异常先查看对应请求的入参/响应与 Console，再关联 Electron 主进程和测试服务日志，缩小到实际失败环节；修复后重复原操作并做关联用例回归。不得通过直接改数据库或仅调用接口来替代需要点击的验收路径；测试数据准备和独立计数核对可以使用只读脚本。

最终交付执行记录，包含通过/失败/未验证清单、实际提交号、关键截图与已脱敏日志。若本轮产生修复，更新提交后复测受影响用例。所有结果基于测试环境自身数据，测试与生产资源不做同步。
