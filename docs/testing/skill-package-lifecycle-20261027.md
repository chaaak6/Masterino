Source archives may contain a repository wrapper. A unique SKILL.md can be located and repacked without losing resources; ambiguous archives fail with an actionable directory error. Published Market artifacts contain SKILL.md at their root and fit the normalized-package policy. Final consumer limits must accept every artifact that publication accepts. Old clients with a 2,000-entry cap remain incompatible with large packages and require an updated app; do not claim server-only compatibility.

Use the same shared policy module across server, Market, admin and device. Add no database migration, parallel importer, task framework, or UI automation suite. Keep legacy uploads compatible. Invalid purpose/signature, oversized streams and mismatched bytes/hash fail before storage confirmation. Never replace an installed record until all new resources and the normalized archive are ready. Bounded resource concurrency; retain content-addressed deduplication.
