# 工作区 Markdown 预览验收用例

## 环境与准备

- 在已有的本地测试 Electron App 使用 `test-server` 测试配置和测试账号，确认启动日志的 API 与 Gateway 均为 `mlai-test.bielcrystal.com`。服务端如需更新，在 `masterino-test` 复用现有服务。记录客户端 SHA、服务端镜像标识及执行日期。
- 新建一个临时测试目录及对应测试话题。只使用合成文件。需要跨设备验证时，在已绑定的测试设备工作区放置同一套样例。记录本机、Web 远端和 Windows 的结果。
- 验收通过文件树、文件标签、界面控件或键盘完成。打开 DevTools 保存 Console 与 Network，配合 Electron 主进程日志和所需的测试服务日志排查。记录步骤、期望、实际、证据及复验结果。
- 自动化覆盖文件预览组件的可见行为、Portal 文件标签导航、设备预览结果和 Electron 媒体打开动作。IPC、系统播放器和设备 RPC 在真实 App 或远端入口另行验收。

## 功能验收

| ID   | 操作                                                                                                     | 预期                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| MD01 | 从「文件」树打开 README，观察横幅、HTML GIF 和两张标准 Markdown 图片。缩窄文件面板。                     | 四处图片都显示，GIF 播放，alt 可读，横幅受面板宽度约束。HTML 标签在原文可查看。                        |
| MD02 | 检查五种 GitHub 提示块、普通引用、代码中的 HTML 与提示标记。切换浅色和深色主题。                         | 五种提示块可区分，同行粗体和同行普通正文完整，保留第二段及行内链接。普通引用和代码具有各自原有的语义。 |
| MD03 | 检查三处失败图片，滚动后切到另一文件，再返回 README。                                                    | 失败有替代文字或文件名，无 alt 时仍可识别缺图。切换文件不会短暂展示其他图片。                          |
| MD04 | 点击两个同名标题链接，再按键盘 Tab 和 Enter 导航。访问不存在的章节，往返脚注。                           | 分别定位到面板内两个标题，焦点与滚动正确，找不到章节有反馈。脚注双向可用，应用页面路由不跳转。         |
| MD05 | 点击带片段指南链接，先打开目标原文并作未保存编辑，再从 README 重复打开。进入深层文件，点击上级相对链接。 | 复用目标标签，跳到目标章节，未保存编辑保留。合法的上级相对链接打开同设备的工作区文件。                 |
| MD06 | 用鼠标及键盘分别激活 HTML 和 Markdown 的链接图片。本机视频标签点击「用系统播放器打开」。                 | 每次只打开目标视频标签，图片灯箱不会随之打开。本机播放器可播放合成 MP4。                               |
| MD07 | 点击缺失文件。用工作区外部的合成文件、越界相对链接及指向外部的符号链接验证范围。                         | 缺失或越界给出失败反馈，没有读到工作区外样例，系统播放器无法通过关联内容打开越界媒体。                 |
| MD08 | 通过已绑定的远端设备打开 `.markdown`、`.mdx` 和 `.md`，查看图片和跨文件链接，再打开远端 MP4。            | 三种扩展名都进入预览，远端资源沿当前设备读取。视频标签明确提示远端预览不可用，设备离线时给出失败反馈。 |
| MD09 | 用鼠标和键盘展开、折叠详情。切换原文检查标记，并观察 Console。                                           | 折叠语义正确，链接图片及其他内容无无效 DOM 嵌套警告。                                                  |
