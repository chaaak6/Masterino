## 容错边界

这是 localFile 属性解析器，不是 shell 或 URL 解析器。正确配对的属性引号优先；缺少/混合/重复外层引号仅在根路径和标签属性边界明确时恢复。不自动 URL 解码、替换分隔符、Unicode 归一化或模糊查找文件。file:// 等 URL 使用现有独立链接解析入口，不作为此标签的原生路径打开。重复 path、吞掉下一属性的歧义引号、空值、控制字符会显示无效路径提示。

历史数据库中的消息原文保持不变；重新渲染即可使用新逻辑。桌面客户端内置代码需要后续正常发版才会生效，本 PR 不执行发布。
