# Masterino 附件体验验收记录

基线为最新 main `be3e7172`，实现分支 `codex/attachment-experience`。验收使用本地源码 Electron 和本地 Web 前端，后端为测试集群 `mlai-test.bielcrystal.com`，专用测试账号。未修改或发布生产、测试集群服务配置。

## 已取得的证据

- Electron：首页真实文件选择三图，输入区 3/10；同一预览器从 2/3 切到 3/3。
- Electron：首页真实选择十二张合成 PNG，仅十张就绪，十一和十二列入拒绝清单。移除中间图后 9/10，确认清理拒绝项后恢复发送。
- Electron DevTools：清理 Network 后记录本机附件准备，出现本地 blob 图片与常规查询，未出现对象存储 PUT。
- Electron：移除至两图并实际发送，话题 `tpc_PZtOa413BEPV`，模型回复 `2`；消息区显示同组图片。
- Web：真实文件选择 10,485,761 字节 TXT 与小 TXT 混合批次，超限项在选择阶段拒绝，小 TXT 上传并解析至可发送；关闭客户端说明后状态保留。
- 定向检查：56 个测试通过，涵盖策略、并发名额、同名文件、上传状态及既有消息展示回归。新增测试为策略和 store 行为，没有新增 UI 单测。

测试站点的无扩展名调试地址回到已部署页面；现有静态调试 HTML 的 CSP 拒绝 localhost 脚本，因此没有关闭 CSP。Web 使用仅本机监听的临时开发转发入口，前端来自本分支 Vite，后端仍为测试集群。通过正常测试账号登录，不导出或注入已有会话令牌。实际源码 URL 已通过浏览器 DOM 检查确认。
