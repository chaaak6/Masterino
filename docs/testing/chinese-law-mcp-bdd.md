# 内网法条 MCP 测试与验收

状态：用例已定义，尚未开发／部署／验收。基线：main d1226ecf（1.3.12）。

## 范围与边界

新增独立服务、固定公开语料、测试环境部署配置，复用现有共享 MCP 调用和审批发布链路。不修改客户端、模型路由、元典配置、数据库结构及生产部署。

自动化通过 HTTP MCP initialize、tools/list、tools/call 验证真实公开接口；真人验收通过测试管理后台和连接测试集群的 Electron，结合 Network、Console 与服务日志确认。只对协议、数据装载和检索写必要测试，不增加 UI 单测。
