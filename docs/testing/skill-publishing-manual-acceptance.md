# Skill 投稿与正常使用真人验收

验收对象：当前 worktree 的精简投稿升级。所有结果初始为未执行，实际操作后另附日期、源码 SHA、测试 app/服务地址、账号角色、版本、截图、请求及脱敏日志，不以代码阅读或自动测试替代真人通过。

## 环境与资料

使用独立测试 app/profile、测试服务和 masterino-test 集群，禁止测试写入生产。准备作者 A、普通安装用户 B、审核管理员 R；每轮用唯一 skill 名称。构造包含 SKILL.md、references/example.md、scripts/probe.py 和 assets/example.txt 的正常包，脚本只读取固定测试文本并输出标记；另备缺 SKILL.md、无 frontmatter、同名不同内容、路径穿越包。真实模型使用测试账号已有授权。

每个用例记录实际 UI、Network 状态和响应业务状态、Console 与服务日志；任何失败先定位并修复，再重跑该用例及关联正常路径。测试结束撤回/拒绝/下架仅本轮测试资源，保留审计，不删除原有资源。

## 验收记录规则

每项状态只可为通过、失败待修复、受环境阻塞、未执行；不得把未覆盖写为通过。主链路 P01–P12、I01–I06、R01/R03/R04 必须有 computer use 证据。关键越权/版本竞态可辅以真实服务请求检验，注明执行方式。仅增加少量包导出、来源复用与审核版本校验的逻辑回归测试，不新增大量 UI 自动化用例。
