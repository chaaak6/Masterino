## Visual acceptance and limits

Actual quarterly.pptx was rendered using test-only LibreOffice and PDF tools. The first renderer run lacked CJK fonts; a local fontconfig file pointing to existing macOS font directories fixed the renderer without changing host settings or the App. All five Chinese pages were inspected. The chart, table and group render correctly. The first KPI's unit wrapped and the chart footer was crowded, so an additional real-agent editing case was run. The agent corrected a generated-script Length/int error and then caught and corrected its own mistaken legend overlay setting. Final quarterly-polished.pptx preserves the source hash, five notes and native chart data/labels; only slide2.xml and slide3.xml changed. Fresh rendering confirmed the KPI unit stays on one line and the chart/legend clear the visible footer. Node and Git still succeeded afterward.

The installed PowerPoint is an old Intel binary and failed to launch with NSOSStatus -10669. Native PowerPoint/WPS GUI acceptance therefore remains unverified; LibreOffice rendering is not a substitute for that claim. Arbitrary SmartArt/OLE/animation fidelity and Windows GUI acceptance remain unverified.
